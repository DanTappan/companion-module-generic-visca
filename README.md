# companion-module-generic-visca

This module uses the Sony Visca protocol to control PTZ cameras. 

It is based on the v2.7.5 tag of companion-module-sony-visca. Later branches of that project added SONY specific functionality which did not work will with other manufacturers cameras. This 
module is targeted with supporting basic VISCA functionality and is intended to work with any PTZ cameras that uses the VISCA protocol over UDP. If you need manufacturer specific functions either find a camera specific module, or use the custom VISCA command action
